Seksyen 3 Manual Makmal Terbuka

5 Tema Aplikasi Kejuruteraan Terbuka

Pilih atau sesuaikan satu daripada 5 tema ini untuk cadangan Minggu 4 & demonstrasi Minggu 7.

01 Ergonomik Kesihatan

Sistem Pemantau Postur Boleh Pakai

Peranti boleh pakai pada tulang toraks atas bagi memantau kecondongan tulang belakang ketika bekerja di meja untuk mengelakkan kecederaan servikal.

Fungsi MPU6050:

Mengukur sudut pitch bahagian atas tulang belakang relatif kepada paksi menegak asal.

Kawalan Penggerak:

LED Hijau (postur baik); LED Merah berkedip + bip pembaz sekiranya membongkok > 15° melebihi 5 saat.

02 Keselamatan Automotif

Topi Keledar Pengesan Mengantuk Pemandu

Topi atau topi keledar keselamatan yang mengesan lena mikro (micro-sleep), kepala tersengguk pantas, dan kehilangan tumpuan pemandu.

Fungsi MPU6050:

Mengesan halaju sudut senggukan pantas (giroskop) atau kecondongan kepala ke bawah melebihi 25°.

Kawalan Penggerak:

LED Hijau status aktif; siren pembaz frekuensi tinggi + LED Merah berkelip pantas untuk mengejutkan pemandu.

03 Kejuruteraan Awam

Pemantau Gegaran & Seismik Struktur Bangunan

Alat pemantau integriti struktur yang dipasang pada jambatan atau tiang bangunan bagi mengesan anomali getaran mekanikal dan gempa.

Fungsi MPU6050:

Pensampelan vektor magnitud pecutan dinamik bersih (√(Ax²+Ay²+Az²)) menolak komponen 1g graviti.

Kawalan Penggerak:

Hijau (Stabil), Amaran LED Merah berkelip perlahan jika gegaran >1.3g, siren penuh jika gegaran kritikal >2.0g.

04 Keselamatan Biomedikal

Sistem Keselamatan Pengesan Jatuh Warga Emas

Peranti tali pinggang pintar untuk pesakit geriatrik atau pekerja altitud tinggi bagi mengesan impak insiden rebah dan jatuh.

Fungsi MPU6050:

Algoritma 3 fasa: Jatuh bebas (≈0g) → Impak lantai tajam (>2.8g) → Tidak bergerak berbaring.

Kawalan Penggerak:

Strob LED Merah kecemasan + corak bunyi SOS pembaz (3 pendek, 3 panjang, 3 pendek).

05 Keselamatan & IoT

Kunci Keselamatan Pintar Corak Gerakan

Mekanisme verifikasi keselamatan tanpa kunci berasaskan jujukan orientasi spatial rahsia (cth. Condong Atas → Bawah → Guling Kanan).

Fungsi MPU6050:

Mesin Keadaan Terhingga (FSM) mengesan peralihan orientasi dalam tetingkap masa yang ditetapkan.

Kawalan Penggerak:

LED Hijau + Nada Berkembar riang (Akses Dibenarkan); LED Merah + Siren Kunci Sekatan jika salah.

Kumpulan pelajar dialu-alukan mengemukakan aplikasi kustom baharu (seperti pengimbang dron, kawalan lengan robotik, penjejak biomekanik sukan).

Templat Kod Asas Arduino C++ (Minggu 3 & 4)

                        
                    

                    
/*
 * =========================================================================
 * BDA37601 Makmal Terbuka Sistem Kawalan / Open-Ended Control Laboratory
 * Pensyarah / Pembangun Modul: Ts. Dr. Hanani Abd Wahab
 * Jadual 7 Minggu: Integrasi MPU6050 dengan Kawalan Penggerak (LED & Pembaz)
 * Perkakasan: Arduino Uno / Nano + MPU6050 + 2x LED + Pembaz Piezo
 * =========================================================================
 */

#include <Wire.h>
#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>

Adafruit_MPU6050 mpu;

// Takrifan Pin Penggerak / Actuator Pinout Definitions
const int PIN_LED_GREEN = 2;  // Penunjuk keadaan normal / Normal state
const int PIN_LED_RED   = 3;  // Penunjuk keadaan amaran / Alarm indicator
const int PIN_BUZZER    = 8;  // Pembaz amaran audio / Auditory alarm

// Konfigurasi Ambang Kecondongan / Tilt Threshold (Minggu 3)
const float AMBANG_TILT_DEG = 30.0;

void setup() {
  Serial.begin(115200);
  while (!Serial) delay(10);

  // Tetapkan mod pin output
  pinMode(PIN_LED_GREEN, OUTPUT);
  pinMode(PIN_LED_RED, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);

  // Inisialisasi bas I2C penderia MPU6050
  if (!mpu.begin()) {
    Serial.println("Ralat: Cip MPU6050 tidak dijumpai! Periksa wayar I2C (SCL/SDA).");
    while (1) {
      // Kelipkan LED merah jika ralat sambungan
      digitalWrite(PIN_LED_RED, HIGH);
      delay(150);
      digitalWrite(PIN_LED_RED, LOW);
      delay(150);
    }
  }

  Serial.println("MPU6050 Berjaya Dikesan & Beroperasi!");
  mpu.setAccelerometerRange(MPU6050_RANGE_4_G);
  mpu.setGyroRange(MPU6050_RANGE_500_DEG);
  mpu.setFilterBandwidth(MPU6050_BAND_21_HZ);
}

void loop() {
  sensors_event_t a, g, temp;
  mpu.getEvent(&a, &g, &temp);

  // 1. Pengiraan Sudut Pitch & Roll Berasaskan Trigonometri
  // Pitch = atan2(Ay, sqrt(Ax^2 + Az^2)) * 180 / PI
  float pitch = atan2(a.acceleration.y, sqrt(a.acceleration.x * a.acceleration.x + a.acceleration.z * a.acceleration.z)) * 180.0 / PI;

  // Roll = atan2(-Ax, Az) * 180 / PI
  float roll = atan2(-a.acceleration.x, a.acceleration.z) * 180.0 / PI;

  // Magnitud kecondongan maksimum
  float maxTilt = max(abs(pitch), abs(roll));

  // 2. Output Data Telemetri Bersiri (Serial Monitor & Plotter)
  Serial.print("Pitch:"); Serial.print(pitch);
  Serial.print(" Roll:"); Serial.print(roll);
  Serial.print(" MaxTilt:"); Serial.println(maxTilt);

  // 3. Kawalan Logik Ambang Penggerak (Threshold Logic)
  if (maxTilt >= AMBANG_TILT_DEG) {
    // Keadaan Terpicu / Triggered State (Tilt >= 30 deg)
    digitalWrite(PIN_LED_GREEN, LOW);
    digitalWrite(PIN_LED_RED, HIGH);
    tone(PIN_BUZZER, 1800); // Isyarat audio frekuensi 1.8 kHz
  } else {
    // Keadaan Normal Selamat / Safe State (Tilt < 30 deg)
    digitalWrite(PIN_LED_GREEN, HIGH);
    digitalWrite(PIN_LED_RED, LOW);
    noTone(PIN_BUZZER);
  }

  delay(40); // Kadar pensampelan 25 Hz
}
