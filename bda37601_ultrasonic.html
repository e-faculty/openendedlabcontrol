BDA37601 Open-Ended Control Laboratory

Topik: Topic: Ball & Beam Balancing Control. Sistem penanda aras kawalan klasik di mana pasukan pelajar mengimbangkan bebola pada kedudukan sasaran (setpoint) menggunakan sensor ultrasonik HC-SR04 dan motor servo dengan algoritma PID gelung tertutup. Modul dan platform dibangunkan oleh Ts. Dr. Hanani Abd Wahab. A premier benchmark control system where student teams stabilize a rolling ball at arbitrary setpoints along a beam using HC-SR04 ultrasonic distance sensing and servo motor closed-loop PID feedback. Developed by Ts. Dr. Hanani Abd Wahab.

Gandaan Pengawal PID / PID Controller Gains

Feedback Loop
Proportional (Kp) 1.80

Menjana daya kembali ke sasaran; nilai lampau menghasilkan ayunan mampan. Restores ball toward target; high values induce sustained oscillation.

Integral (Ki) 0.15

Menghapuskan ralat keadaan mantap; nilai terlampau tinggi menyebabkan lajakan windup. Eliminates steady-state offset; excessive values induce windup overshoot.

Derivative (Kd) 2.40

Bertindak sebagai peredam kelajuan bola; penting untuk mengelakkan bola terlontar. Dampens ball speed; essential to arrest inertia and prevent runaway.

01 Trajectory Tracking

Penjejak Trajektori Multi-Setpoint Dinamik Dynamic Multi-Setpoint Trajectory Follower

Sistem tidak sekadar mengimbang pada 1 titik pegun; ia menggerakkan bola secara automatik mengikut jadual koordinat (contohnya 12cm → 28cm → 20cm). The system stabilizes across dynamic target waypoints, smoothly moving the ball between scheduled locations with minimal derivative kick.

02 Industrial Testbed

Rig Penolakan Gangguan Aliran Udara / Angin Aerodynamic Wind Disturbance Rejection Rig

Kipas DC 5V mengenakan daya tiupan berterusan terhadap bebola. Tindakan integral (Ki) membina kecondongan pengimbang bagi menghapuskan ralat. An external air stream displaces the ball, demonstrating how integral action (Ki) dynamically counters persistent unmodeled bias forces.

03 IoT Telemetry

Papan Pemuka Telemetri & Kawalan IoT Masa-Nyata IoT Real-Time Control & Telemetry Dashboard

Menstrim data jarak, usaha servo, dan ralat melalui WebSerial atau WiFi ke komputer untuk analisis graf tindak balas langkah secara langsung. Streams high-speed distance and actuator telemetry over WebSerial or WiFi, enabling live gain-tuning and transient parameter calculation.

04 Adaptive Control

Pengawal Penjadualan Gandaan Adaptif Dwi-Zon Dual-Zone Adaptive Gain-Scheduled Controller

Mengubah nilai gandaan Kp & Kd secara dinamik apabila bebola menghampiri zon sempadan hujung rasuk bagi mengelakkan bola terlajak keluar. Switches between fast center gains and aggressive edge-braking derivative gains to arrest high velocities near beam boundaries.

05 Kinetic Control

Sistem Tangkapan Bebola & Penstabilan Pantas Ball Catch, Soft-Landing & Quick-Balance System

Bebola dijatuhkan dari tanjakan luar. Mesin keadaan (FSM) mengesan impak ketibaan serta-merta dan mencondongkan rasuk untuk menyerap tenaga impuls. A ball introduced from a ramp is cushioned through instantaneous counter-tilt shock absorption before transitioning into fine PID balance.

                            Peringatan Keselamatan Penting: Kuasa Luaran 5V Berasingan untuk Servo!
                            Critical Safety Warning: External 5V Power for Servo!
                        
                        

                            Motor servo menarik arus puncak setinggi 500mA–1000mA ketika menggerakkan rasuk. DILARANG menyambung kuasa servo terus dari pin 5V Arduino kerana ini menyebabkan mikropengawal mengalami *brownout*, reset berulang, dan bacaan sensor ultrasonik menjadi rawak. Gunakan penyesuai kuasa 5V 2A dengan Ground (GND) sepunya.
                            A loaded servo draws up to 500mA–1000mA peak current. DO NOT power the servo directly from the Arduino 5V pin as this causes voltage brownouts, MCU resets, and ultrasonic data corruption. Use an external 5V 2A power rail with shared common GND.

/*
 * BDA37601: Ball and Beam Balancing Control
 * Pensyarah / Pembangun Modul: Ts. Dr. Hanani Abd Wahab
 * HC-SR04 Ultrasonic Distance Sensor + SG90/MG996R Servo Motor
 * Algorithm: Discrete PID Control with Median Noise Filter & Anti-Windup
 */

#include <Servo.h>

// --- Hardware Pin Definitions ---
const int PIN_TRIG = 9;
const int PIN_ECHO = 10;
const int PIN_SERVO = 6;

Servo beamServo;

// --- Mechanical Calibration Parameters ---
const int SERVO_HORIZONTAL = 95;  // Servo angle when beam is perfectly level (θ₀)
const int SERVO_MIN = 65;         // Max downward tilt limit (-30 deg)
const int SERVO_MAX = 125;        // Max upward tilt limit (+30 deg)

// --- Control Parameters ---
double setpoint = 20.0;           // Desired ball position (cm from sensor)
double distance = 20.0;           // Current filtered ball position (cm)

// PID Controller Gains (Tune via experimental Ziegler-Nichols method)
double Kp = 1.80;                 // Proportional Gain
double Ki = 0.15;                 // Integral Gain
double Kd = 2.40;                 // Derivative Gain

// State Tracking
double error = 0.0;
double previousError = 0.0;
double integral = 0.0;
double derivative = 0.0;
unsigned long lastTime = 0;
const unsigned long SAMPLE_TIME_MS = 40; // 25 Hz loop frequency

// Helper Function: Measure Raw Ultrasonic Distance with 3-Point Median Filter
double readUltrasonicDistance() {
  double readings[3];
  for (int i = 0; i < 3; i++) {
    digitalWrite(PIN_TRIG, LOW);
    delayMicroseconds(2);
    digitalWrite(PIN_TRIG, HIGH);
    delayMicroseconds(10);
    digitalWrite(PIN_TRIG, LOW);

    long duration = pulseIn(PIN_ECHO, HIGH, 30000); // 30ms timeout (~5m)
    if (duration == 0) {
      readings[i] = distance; // Fallback to last valid reading if echo drops
    } else {
      readings[i] = (duration * 0.0343) / 2.0;
    }
    delay(5);
  }

  // 3-value median selection
  if ((readings[0] <= readings[1] && readings[1] <= readings[2]) || (readings[2] <= readings[1] && readings[1] <= readings[0]))
    return readings[1];
  else if ((readings[1] <= readings[0] && readings[0] <= readings[2]) || (readings[2] <= readings[0] && readings[0] <= readings[1]))
    return readings[0];
  else
    return readings[2];
}

void setup() {
  Serial.begin(115200);

  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);

  beamServo.attach(PIN_SERVO);
  beamServo.write(SERVO_HORIZONTAL); // Initialize beam level
  delay(1000);

  Serial.println("Ball & Beam PID Controller Initialized.");
  Serial.println("Developed for BDA37601 by Ts. Dr. Hanani Abd Wahab");
  Serial.println("Format: Setpoint, CurrentDistance, ServoAngle");
  lastTime = millis();
}

void loop() {
  unsigned long now = millis();
  unsigned long timeChange = (now - lastTime);

  if (timeChange >= SAMPLE_TIME_MS) {
    // 1. Acquire Filtered Ball Position
    distance = readUltrasonicDistance();

    // Bound check: Ignore out-of-track reflection spikes
    if (distance < 3.0) distance = 3.0;
    if (distance > 40.0) distance = 40.0;

    // 2. Compute PID Terms
    double dt = (double)timeChange / 1000.0; // convert to seconds
    error = setpoint - distance;

    // Integral with Anti-Windup Clamping
    integral += (error * dt);
    integral = constrain(integral, -25.0, 25.0);

    // Derivative on Error
    derivative = (error - previousError) / dt;

    // Total PID Output (Control Effort)
    double output = (Kp * error) + (Ki * integral) + (Kd * derivative);

    // 3. Map PID Output to Servo Angle
    int servoAngle = SERVO_HORIZONTAL - (int)output;
    servoAngle = constrain(servoAngle, SERVO_MIN, SERVO_MAX);

    beamServo.write(servoAngle);

    // 4. Telemetry Output for Serial Plotter
    Serial.print("Setpoint:"); Serial.print(setpoint);
    Serial.print(" Distance:"); Serial.print(distance);
    Serial.print(" Angle:"); Serial.println(servoAngle);

    // Update state for next cycle
    previousError = error;
    lastTime = now;
  }
}
